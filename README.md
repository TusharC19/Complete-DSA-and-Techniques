# Complete DSA and Techniques

This repository is my personal collection of **Data Structures and Algorithms (DSA)** concepts, problems, and techniques that I’ve studied and practiced so far.  
It serves as a reference, a learning journal, and a place to organize solutions and notes.

---

## 📂 Folder Structure
- **Complete DSA/** → Core concepts, notes, and implementations of standard data structures and algorithms.
- **ALL_Dynamic_Programming_Sources/** → Focused problems and solutions related to dynamic programming.

---

## 🎯 Purpose
- To consolidate all my DSA learning in one place.
- To practice problem-solving and track progress.
- To build a reference library I can revisit anytime.

---

## 🛠️ Topics Covered
- Arrays, Strings, Linked Lists  
- Stacks, Queues, Deques  
- Trees, Graphs, Tries  
- Sorting and Searching techniques  
- Recursion and Backtracking  
- Dynamic Programming  
- Greedy Algorithms  
- Bit Manipulation  
- Advanced techniques (Segment Trees, Fenwick Trees, etc.)
